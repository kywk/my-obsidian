my-obsidian

授權聲明確認

Obsidian 的 renderer 在啟動時會向宿主（這個 server）索取一段聲明字串，並與它自己內建的那份 逐字元比對；不符就中止啟動。因此 server 必須拿到那段字串才能把 renderer 送進瀏覽器。

這段字串不存在於本專案的程式碼裡。它只能由操作者本人從本機的 vendor/obsidian/app.js 取出，貼到下面的欄位，寫入 server 設定檔後注入 renderer。 按下確認的人，就是做出該聲明的人。

讀取目前狀態…

步驟一：從 vendor bundle 取出字串

bundle 內只有一處 sendSync("terms")，比對用的字面值就緊接在它前面。 在專案根目錄執行（macOS 會直接放進剪貼板；其他系統請去掉 | pbcopy，自行複製輸出）： 

grep -o '"[^"]\{40,\}"[^"]*sendSync("terms")' vendor/obsidian/app.js | sed 's/^"//; s/".*$//' | pbcopy

也可以在編輯器打開 vendor/obsidian/app.js，搜尋 sendSync("terms")， 複製它左邊的那個字串字面值。請完整複製，不要手打、不要改寫。

同一件事用 Node 做（與 tools/lib/cdp.mjs 的取出方式相同）：

node -e 'const fs=require("fs");const s=fs.readFileSync("vendor/obsidian/app.js","utf8");const at=s.indexOf(".ipcRenderer.sendSync(\"terms\")");const o=s.lastIndexOf("\"",at-2);const c=s.lastIndexOf("\"",o-1);process.stdout.write(s.slice(c+1,o))' | pbcopy

步驟二：閱讀並逐項確認

my-obsidian 不是 Obsidian。它與 Obsidian（Dynalist Inc.）沒有隸屬、 贊助或背書關係。Obsidian 的程式碼、名稱、商標與著作權全部歸 Obsidian 所有； 本專案只提供宿主環境，並不包含也不散布任何 Obsidian 程式碼—— renderer 是從你自己已安裝的官方 Obsidian 取得。

完整說明見專案根目錄的 NOTICE.md。Obsidian 的條款以官方為準： obsidian.md/terms。

請逐項勾選（全部必選）

步驟三：貼上並確認

這個聲明是什麼，以及它的界線

把 bundle 送進他人的瀏覽器，在字面上就落在該聲明的射程內。 私有自用（自己機器、自己 vault）與對其他人提供服務是兩件不同的事； 後者需要 Obsidian team 的明示同意。這個判斷由操作者承擔。

server 只做兩件事：把你確認過的同一段字串注入 renderer 的 boot 物件，以及在你未確認前拒絕提供 /obsidian/app.js。

其他寫入方式

沒有瀏覽器可用時，也可以沿用環境變數 TERMS_ACK（它優先於設定檔）；同一台機器上兩者擇一即可。 設定檔路徑由 MYOBS_CONFIG 決定，預設是 ~/.config/my-obsidian/config.json， 權限為目錄 0700、檔案 0600。
